This chapter covers the design, implementation and evaluation of a newly revised version of the CloudSentinel framework.

\section{Selected improvement and objectives}

Based on the evaluation of the base CloudSentinel framework, the following components have been designed:

\begin{itemize}
    \item Workflow Guide
    \item Monitored Environment configuration
    \item Data Catalogue
    \item Detector Onboarding
    \item Model Training and Saved Models
    \item Anomaly Detection Model Comparisons
    \item Robustness Analysis
    \item Live Monitoring and RCA
    \item Data and Result Provenance.
\end{itemize}
