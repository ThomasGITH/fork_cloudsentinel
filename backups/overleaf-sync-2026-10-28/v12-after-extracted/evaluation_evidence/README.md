# Evaluation evidence index

This directory contains the retained evidence for the evaluation in Chapter 9. The numbered folders follow the same order as the evaluation sections.





## 1. Dataset management, training, comparison, and detector integration

Shared environment details for evaluations 1--4, regression-test and functional-retest output, the independent score check, the saved workflow run bundle, training and comparison records, labels, traceability checks, and detector adapter snapshots.

## 2. Performance and resource use

Timing, CPU, and memory measurements for the selected comparison workloads.

## 3. Application scaling and changing pod identities

Kubernetes state snapshots, frontend availability checks, Prometheus query output, Data Catalogue fetches, and the bounded second-worker attempt.

## 4. Known-fault tests in Online Boutique

Fault timing, Prometheus and Kubernetes verification, monitoring-session output, detector behaviour, and RCA details.

## 5. RCAEval Train Ticket benchmark

The frozen protocol, selected cases, shared feature profile, detector results, BARO rankings, and source hashes.

## 6. NaaVRE external environment

The read-only collection protocol, scripts, and retained aggregate results. Credentials and raw operational telemetry are deliberately excluded.

## 7. User evaluation

Reserved for the anonymised protocol, notes or transcripts that may be retained, coding results, and the final feedback summary.

Raw model artefacts, private server paths, credentials, and protected operational telemetry are not included.
