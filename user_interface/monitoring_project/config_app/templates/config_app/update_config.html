Prometheus source used by new catalogue datasets

The Data Catalogue resolves the source identifier cluster-default inside the Data Ingestion deployment. Configure that service with CATALOGUE_CLUSTER_DEFAULT_PROMETHEUS_URL. Keep it aligned with PROMETHEUS_URL when both components should query the same Prometheus server.

This separation is important: changing only the user-interface endpoint cannot safely reconfigure the independently running Data Ingestion service.
